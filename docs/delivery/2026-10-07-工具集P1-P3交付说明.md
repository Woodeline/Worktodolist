## 1. 采用的方法

1. **先立地基，再挂消费者。** 先把 ToolShell 骨架、registry 声明式字段、工具级 ErrorBoundary 做出来，再把 RTI 改造为骨架的第一个消费者 —— 用真实工具反向验证骨架。
2. **`lib/` 纯函数先行。** 每个工具的能力先落成 `src/lib/<domain>/*.js` 纯函数并配 `*.test.js`，组件只做「取值 → 调纯函数 → 渲染」。算法可单测是进 registry 的**准入门槛**（待拍板 ③）。
3. **门禁驱动收口。** 每层落地立刻把「外壳契约 / 裸值 / 对比度 / 设置结构 / 响应式」这些既有门禁泛化到新工具上。
4. **删功能 = 删到底 + 门禁跟着走。** 这一轮的范围收紧不是"藏起来"，而是把组件、`lib/` 纯函数与测试、registry 条目、接线、样式、门禁断言一起撤掉 —— 只留注释说明为什么删。

## 8. 本轮（收紧）同步修正的门禁口径

删功能本身没产生产品缺陷，但**门禁必须跟着范围走**，否则会变成假失败或假通过：

1. `qa-tools.mjs`：分组折叠头下限从 `>= 3` 改为 `>= 2`（GROUPS 现为 2 组）。
2. `qa-settings.mjs`：结构断言从「2 组 / 10 行」改为「1 组 / 6 行 / 分组标题只剩「AI 兜底解析」」。
3. `qa-settings.mjs`：**新增反向断言**「联网工具分组已整体移除（白名单 / 超时 / 响应上限控件都不在）」—— 一个没有消费者的联网开关比没有这个开关更糟（会让人误以为数据可能出机）。
4. `qa-settings.mjs`：删除 4c 联网段落（其被测对象已不存在），改为一段注释说明它去了哪、以及由哪条断言接管「不能被悄悄加回来」。
5. `qa-css-check` 复跑确认：清理后仍为 `缺失 0 / 运行时拼接值缺失 0 / 裸值 0`，剩余「未用」项（`is-*`、`tool-layout-*` 等）均为动态拼接误报，与删除前基线一致。

## 9. 更早一轮发现并修复的真实缺陷（历史记录）

门禁抓到的**真缺陷**（不是误报）：

1. **`RtiTool` hook 顺序回归** —— `useRestoredState` 误写在 `useState` 初始化器内，hook 链错位整页崩 → 提到顶层。
2. **`SettingsPage` 白名单受控输入类型不匹配** —— onChange 存字符串、渲染读 `allowHosts.join()`，字符串没有 `.join` → 整页崩。（该字段已随 T4 删除）
3. **`SettingsPage.doTest` 引用未定义的 `draftNorm`** —— 点「测试 AI 连接」必然 ReferenceError → 改用 `aiDraft`。
4. **`NetCheckTool` 直读未配置的 `netCfg`** —— `loadNetConfig()` 未配置时返回 `null` → 崩溃。（该工具已删除）
5. **`StatsTool` 条形图 `none` 档不可见** —— 填充误用 `var(--ramp-1)` 与轨道同色 → 改 `var(--muted)`。
6. **`.tool-col-in` / `.tool-col-out` 未在 `index.css` 定义**（`test:ui` 抓到）。
7. **`qa-responsive.mjs` 探测点过期** —— `.rti-tab` / `.rti-row-del` 未随类名迁移 → 4 项假失败，改 `.tool-tab` / `.tool-row-del`。

## 10. 条目 16「第三方脚本式工具注册」为什么不做

沿用方案结论：**当前不做**。

1. 会直接击穿「数据主权优先」红线 —— 第三方脚本一旦能进 registry，就等于把「写 `todo.txt`」的授权口径交给外部代码。
2. 与「算法必须在 `lib/` 且可单测」的准入门槛冲突 —— 外部脚本无法纳入本仓 vitest 门禁。
3. 范围收紧后工具只剩 4 个，「工具太多找不到」这个痛点更加不存在。

## 11. 已知取舍与边界（不要顺手改掉）

- `.rti-table { min-width: 420px }` —— 手机端表格横滚，而不是把数字格压到 ~120px 让数据读不全。
- `--control-line` ≠ `--border` —— 前者供交互控件边界（WCAG 1.4.11 要求 ≥3:1），后者是装饰性发丝线。
- 复选框选中态用 `--accent` 蓝不用 `--ok` 绿 —— 勾选是「选择」语义，不是「成功」语义。
- `--ramp-1..5` 顺序色阶**方向随主题而变**（明色 1 最浅、暗色 1 最暗），单调性断言写成方向无关；轨道固定 `--ramp-1`，「未分类」用 `--muted`。
- 左栏分组**刻意只有一层**，不做三级导航。
- ToolShell 保留 `instant` 版式（当前无消费者）—— 它是外壳契约的一部分。
