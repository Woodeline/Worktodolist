0 · 判读卡

条目结论
一句话新调性 信号仪表 —— 冷灰面板分域、示波器青强调、等宽字符扩权到标题/页签/计数、双线描边与紧凑圆角；工具理性的仪器面板，让「数据 · 状态 · 信号」成为视觉主角。
被推翻的旧口径 2026-10-06 拍板的「贴近原生桌面工具」（跟随系统灰 + 系统蓝）—— 本次推翻其视觉部分：面板层级改为 bg 暗 / surface 亮的反转关系，强调色由系统蓝 #0f5fbf 改为示波器青 #0e7490。结构、交互、令牌架构全部保留。新拍板将写入 MEMORY.md（见 §6 备案）。
不变的纪律红线 ① 数据源唯一（todo.txt / done.txt）；② 间距只有一套，改密度不动卡片留白；③ 组件禁裸值、令牌唯一入口 index.css §1（本次换调零组件改动的前提）；④ AI 兜底四约束；⑤ 明暗同语义等价、语义色冻结。

1 · 背景动机

v0.1.3 → v0.1.6 三轮演进后，结构已经稳定（三页签 / 工具集 4 工具 / 设置集中化 / ToolShell 三版式），但视觉调性仍停留在「系统默认灰 + 默认蓝」——产品有了骨架，没有签名。

三个具体痛点：

  • 面板层级弱：bg（#f0f0f0）与 surface（#ffffff）的关系沿用「窗口灰 + 白卡」的 OS 惯性，surface 亮于 bg 但层级语言与桌面系统混同，缺乏「仪器底座」的分区感。
  • 强调色无辨识度：#0f5fbf 与 Windows 默认蓝同质——选中态、焦点环、主按钮淹没在系统 UI 的海洋里。
  • 气质分裂：mono 字体只出现在数据单元格，标题 / 页签 / 计数仍走 UI 栈；一个以「文本协议 + 信号数据」为本体的产品，最有性格的资源（等宽字符）没有被用足。

时机：组件全面令牌化 + css-check / contrast 门禁已稳定运行（基线 365 tests），换调性的边际成本处于历史最低点——理论上只动 §1 的 ~95 个令牌，组件零改动。这正是本次方案的全部赌注与全部红利。

2 · 方向论述（三候选 + 裁决记录）

Phase 1 以两条正交轴生成候选：血统（工具理性 ↔ 日用感性）× 表现度（素 ↔ 浓）。三候选以同构 DOM 微样张交付（方向候选样张-2026-10-07.html），换调只改令牌——当场实证了「组件禁裸值」红利。

候选轴位机制摘要裁决观察
A · 墨水编辑器工具理性 × 素纸白 / 墨黑双极、单一藏蓝强调、衬线标题克制混排；签名感来自「几乎没有装饰」。与文本协议气质契合，但表现度过素——选中态、状态色、图表都缺乏可仰仗的系统色。
B · 纸感手帐日用感性 × 浓暖纸底、棕橙强调、大圆角 + 软阴影；温度优先。与「高密度工具 / 信号数据」的内容本质冲突：暖调会稀释状态色的可读性。
C · 信号仪表 ✓工具理性 × 中浓冷灰面板分域（bg 暗 / surface 亮反转）、示波器青强调、mono 扩权到标题/页签/计数、双线描边（sh-2 加 1px 描边分量）、圆角收紧一档。与产品内容（todo 文本协议 / RTI 信号 / 图表）同构；换调成本与 A 相当，签名感最强。
裁决记录（决策点① · 2026-10-07）：用户回复「C」，候选 C 当选。A、B 用户未陈述落选理由，按选择结果落选备案；微样张存档于 方向候选样张-2026-10-07.html 备查。

3 · 新令牌系统（差异表 + 对比度徽标）

推导链五步：调性关键词（仪器 · 终端 · 刻度 · 高密度 · 青）→ 视觉机制（冷灰面板分域 + 双线描边 + mono 扩权）→ 令牌值域 → 明暗双套 → 约束回验。

锚点反解法：--bg / --text 两端锚点按正文 4.5:1 反推；中间表面按 Oklch L 等感知明度排布；--control-line 对 surface ≥3:1 反解（WCAG 1.4.11 控件边界）；--accent 对 --accent-fg ≥4.5:1。强调色不做手工钦定——候选列表逐个过「对比度全项 + CVD vs danger/warn」闸门，取 vs-ok ΔE 最大者：#0e7490（浅）/ #46c9ec（暗）。

3.3 REVIEW 项与用户裁决

accent vs ok（浅色主题）· 色相内不可解：能过 4.5:1 文字对比的青色与 ok 绿在 tritanopia（蓝黄色盲，约 0.01% 人群）下明度碰撞——4.5:1 把 accent 明度锁死在碰撞区，色相内数学上无解（5 个候选全试，ΔE 7.2–9.8）。已取候选内最优并如实上报。用户裁决（决策点② · 2026-10-07）：选 A —— 接受现值 + 双编码缓解（产品所有状态均为图标/文字双编码，无纯色辨析场景）。附录 B 中该项标注 REVIEW·A。另：danger vs warn（deutan ΔE≈4.7）为现网既有旧账（语义色冻结、零回归），列入实施后优化清单。
