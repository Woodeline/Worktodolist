# 设置分类侧栏与入口剥离（2026-11-19）

## 背景

设置过去收在应用菜单里，菜单同时承载「外观」三档与「窗口与数据」三项动作。
设置页本身是平铺的八节，靠纵向滚动找内容。2026-11-19 按本轮要求在 Mac 上改成
活动栏独立入口 + 页内分类侧栏，设置内容按大类收纳：

- 应用菜单不再包含「设置…」「外观」「窗口与数据」。
- 活动栏「应用菜单」右侧新增一枚设置按钮，与 `Ctrl+,` 指向同一张页面。
- 设置页左侧三类导航，右侧只展示当前分类。
- 原「外观」组的明暗三档迁入设置页；「列表与阅读」同日并入外观。
- 显示模式撤出设置页，统一走侧栏「日历」入口。
- 窗口置顶撤出设置页，功能保留在活动栏图钉与托盘菜单。
- 数据动作仍归「数据」分类，快捷键三节仍为只读速查。

## 入口与菜单

活动栏底部顺序固定为：

1. 应用菜单
2. 设置
3. 置顶
4. 主题

设置按钮 `title="设置（Ctrl+,）"`，`aria-label="设置"`，紧邻应用菜单。
应用菜单的一级分组缩为五项，全部是列表工作流动作：

```
任务 / 页面 / 列表视图 / 显示模式 / 排序
```

`lib/appMenu.js` 的 `APP_MENU_GROUP_LABELS` 与 `buildAppMenuItems()` 同步收口，
不再接收 `themeItems`、`alwaysOnTop`、`toggleTop`、`openSettings`。
`App.test.jsx` 与 `lib/appMenu.test.js` 用渲染标记和纯函数断言锁定这条边界。

## 设置分类

分类顺序与图标的名唯一来源是 `SettingsPage.jsx` 导出的 `SETTINGS_CATEGORIES`：

| 分类 | id | 图标 | 收纳的设置节 |
|---|---|---|---|
| 外观 | `appearance` | `palette` | 明暗模式 / 外观主题 / 列表外观 / 阅读密度 |
| 数据 | `data` | `database` | 数据 |
| 快捷键 | `shortcuts` | `keyboard` | 全局 / 列表页 / 日历 |

页面默认只展示「外观」，其余两个分类保留在 DOM 中并加 `hidden`，
分类内部各节的偏好状态因此不会在切换时丢掉。切换分类后右侧面板滚动位置归零。

`Icon.jsx` 新增 `palette`、`database`、`keyboard` 三个图标。
设置节顺序是八节：

```
明暗模式 / 外观主题 / 列表外观 / 阅读密度 /
数据 / 全局 / 列表页 / 日历
```

明暗模式三档直接写 `configStore`，与活动栏主题按钮共用 `themeMode` / `onPickTheme`。
数据分类仍保留「手动重载 / 切换目录」两颗真动作。

## 布局与响应式

`index.css` 新增设置主体规则：

```css
.settings-main {
  display: grid;
  grid-template-columns: var(--sidebar-w) minmax(0, 1fr);
}
.settings-nav { /* surface-2 底、右发丝线、三枚导航 */ }
.settings-pane { /* 当前分类独立滚动 */ }
.settings-inner { max-width: var(--rail-max); margin: 0 auto; }
```

- 1280 宽下左侧目录 176px，与任务侧栏同宽；右侧内容上限 900px。
- 768 宽以下目录转横向滚动条，页面改成上下两行。
- 480 宽以下进一步收紧目录项的内边距与图标文字间隙。
- 触屏粗指针下导航项撑到 44px 命中区。
- 分类导航是 `role="tablist"`，支持 ↑↓ / ←→ / Home / End，焦点跟随选中项。
- 当前分类的按钮 `aria-selected="true"`，面板是 `role="tabpanel"` 并由 `aria-labelledby` 关联。

## 门禁

全部在 Mac 环境执行，未在 Windows 运行改动程序。

浏览器验证入口为 `styleguide.html?view=settings`，使用 Mac 上的无头 Chrome。

Chrome 跑响应式检查，不再依赖 Windows 的 Edge 路径。

未重打 Tauri 安装包，因此本轮验证覆盖真实 React 组件、真实 CSS 与浏览器几何，
不覆盖签名后的 `.app` / `.dmg` 产物。

## 别引回来的东西

- 应用菜单里的「设置…」直入口。
- 应用菜单里的「外观」「窗口与数据」两组。
- 设置页里的「列表与阅读」「窗口」两个分类。
- 设置页里的「显示模式」节，以及「窗口置顶」开关。
- 设置页旧的平铺 `.settings-body` 八节布局。
- 旧页脚「随时可查：应用菜单「设置…」/ Ctrl + ,」。
- 设置分类的额外二级标签或说明性副标题。
