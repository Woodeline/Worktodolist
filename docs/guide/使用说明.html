待办清单 · 怎么用

一句话：这是个桌面应用，用大白话打字，它就去改你电脑上的 todo.txt 文件。

你的任务不在应用里，在你自己的文本文件里——位置就是你选定的那个文件夹里的 todo.txt，用记事本就能打开看。 应用只是给它套了个好看的壳。所以应用坏了、关了，任务一条都不会丢。

一、怎么打开（双击桌面图标就行）

  1. 桌面上找那个橙色对勾的图标，名字叫 待办清单-Tauri。
  2. 双击它，然后等着就行 —— 全程不会有黑色窗口冒出来。
  3. 大概 1～3 秒后，应用窗口直接弹出来（原生窗口，不是浏览器）。
  4. 页面上有个按钮，点它 → 在弹窗里选中 todolist 文件夹 → 点「选择文件夹」。
  5. 系统问「是否允许访问文件」时，点 允许。
以后再用：还是双击那个图标，不用再选文件夹，它记得住。 重复双击也没关系——它只会把已经开着的窗口再提到前面来，不会开出第二个。
两个必须知道的点：
  • 不再需要 Edge 或 Chrome —— 窗口由系统自带的 WebView2 渲染，跟浏览器无关。
  • 用完直接把窗口关掉就行。关了就是真关了，不会在后台留服务（想确认见第五节）。
万一双击没反应？
  • 先去 todolist 文件夹，双击 启动待办清单-Tauri.cmd。 它会弹出一个黑色窗口，把出错原因写在窗口里，照着看即可。
  • 想看完整诊断（程序在哪、缺什么），执行 python launch_todolist_tauri.py --status。
  • 如果提示找不到程序，说明这个版本还没构建过 —— 在 todolist-gui 文件夹里执行 npm run tauri:build（需要 Rust 工具链，只在改代码时才用得到）。

二、打开之后怎么用

上面有两个标签页：对话（默认）和 列表。

对话页：打字说话就行

  • 页面中间会给你一排灰色小按钮，都是例子。点一下它就填进下面的输入框，再按 Enter 就执行了。
  • 也可以自己在下面输入框随便打字，按 Enter 发送。
  • 右边那一列是你的任务实时清单，左边的数字就是「第几条」的那个序号。
  • 想反悔：按 Ctrl + Z，或者在输入框里打「撤销」。

列表页：像普通待办软件那样点

  • 按 n 键 → 直接打字 → Enter，加一条。
  • 点任务前面的圆圈 = 完成；点任务这一行 = 改标题、日期、优先级。
  • 按 / 键 = 搜索。

三、能说哪些话（照抄即可）

你打的字它会做什么
加一条 明天 交周报新增任务，截止日自动填明天
加一条 列出购物清单新增任务（标题里带"列出"也不会搞错）
有哪些任务列出所有还没做的，带编号
有哪些任务已完成列出已经做完的
完成 第2条把右边清单里第 2 条标成完成
完成 回测报告按标题找并完成；找到多条会先问你选哪个
把 回测报告 延到下周三改截止日期
标为高 回测报告优先级改成高
删除 第3条删掉（可以用 Ctrl+Z 撤销）
撤销撤回上一步

时间可以说：今天 / 明天 / 后天 / 周五 / 下周三 / 3天后 / 10月8日 / 月底。输入 / 会弹出全部可用说法。

四、常见问题

情况怎么办
窗口打不开先双击 启动待办清单-Tauri.cmd 看报错；还不行就执行 python launch_todolist_tauri.py --status 看诊断。
提示"没有权限访问文件夹"重新点一次「选择文件夹」，在系统弹窗里点「允许」即可。
提示"再点一下就能继续"正常，系统过一段时间要重新确认文件夹权限，点按钮再允许一次，数据不会丢。
说"没听懂"换个说法，或输入 / 看它能听懂哪些词。
怕丢数据任务在 todo.txt 里，每次打开应用会自动在 backup 文件夹存一份当天副本（留最近 30 天）。
想在命令行用原来的 topydo 命令照样能用，两边改的是同一个文件。

五、怎么彻底关掉

平时不用管，直接关窗口就行——关了就是真关了，应用不会驻留后台。想确认确实没在跑：

  1. 打开 todolist 文件夹，双击 停止待办清单-Tauri.cmd。
  2. 看到「已结束 …」或「没有在运行的 Worktodolist.exe」就说明干净了。

关了不影响任何数据——你的任务一直在 todo.txt 里躺着，下次双击图标照样全在。

技术备注（看不懂可跳过）：这是本地桌面应用（Tauri 壳 + 系统自带的 WebView2 渲染）， 直接读写 todo.txt / done.txt，不联网、不经过任何服务器； 对话页是本地规则解析，不是大模型，所以没有网络也能用、也不花钱。
