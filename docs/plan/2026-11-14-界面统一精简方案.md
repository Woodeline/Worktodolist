## 3 目标骨架

```
L0  活动栏 46px                       （不动）
L1  上下文条 36px  ← 列表 / 日历 / 对话
    面包屑：视图名 · 口径 · 计数          右侧：本层动作
L2  页头 44px      ← 设置 / 工具墙 / 工具工作态
    返回 + 22px 标题 + 状态徽标 + 动作
内容区  上留白 16px，卡片内 12px，块间 16px
```

- **删除 `tool-head` 这一层**：返回图标、工具名（22px）、页签、风险徽标、页头动作全部并入 `tool-bar`，高度统一 44px。收益：工具页省 40px、去掉重复的「工具集」两次（`ToolsPage.jsx:201` 与 `:207`）、「我在哪」只出现一次。
- **字阶收口**：22px（`--fs-display`）只作页标题；16px 只作区块名；不再出现「工具工作态标题 16px」这种回退。
- **间距收口**：卡片一律 `--sp-3`（12），块间 `--sp-4`（16），内容区上留白 `--sp-4`；裸值全部换成令牌（`qa-css-check` 只扫 `index.css`，换令牌是唯一能被门禁长期守住的做法）。

## 6 不能动

1. 数据模型：`due:` 仍 `YYYY-MM-DD`、`rem:` 仍 `YYYY-MM-DDTHH:mm`；偏好不进 `todo.txt`。
2. 颜色语义：逾期是整行唯一强色，accent 只表选中/今天/焦点——**精简不得引入彩色分类**。
3. `--nav-h` / `--row-h` 以 `index.css` §1 令牌层为唯一真相源，文档不复制数值。
4. `qa-settings.mjs:241-246` 六节标题顺序等式、`:250` 页头含「只读」、`:249` 行数 ≥12。
5. 无障碍标签（`aria-label` / `title`）不算「说明文案」，**不在删除范围**。
6. 展示文件原文处（写入行、纸页、语法提示）保留原文。
7. 门禁阈值不得为了变绿而放宽。
