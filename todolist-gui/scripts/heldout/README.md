# heldout —— 自然语言识别「长尾考卷」

八轮盲测语料，考的是 `src/lib/nlRules.js` + `src/lib/nlRef.js` 组成的本地规则引擎
（零模型、零出网）。总入口在上一层：

```bash
node scripts/qa-nl-heldout.mjs            # 跑全部八轮
node scripts/qa-nl-heldout.mjs --round 8  # 只跑一轮
node scripts/qa-nl-heldout.mjs --verbose  # 看每轮完整输出
```

## 为什么是八轮，而不是一份大合集

项目评测纪律：**每一轮的用例都写于上一轮补齐之后，未参与任何调参**。

- 一轮补齐之后，它的语料就退化为「照着规则写的考卷」—— 词表是照着这些句子补的，
  再跑满分只证明规则没写坏，证明不了规则够宽。
- 所以每轮的价值在**首跑成绩**（各文件头已冻结，禁止回填），不在重修后的通过率。
- 前六轮是能力探针（摸底、定补漏优先级），恒退出 0；第七、八轮是**硬门**，
  失败即退出 1，由 `npm run test:nl:heldout` 串起来。

## 轮次

| 文件 | 考什么 | 性质 |
|---|---|---|
| `round-01.mjs` | 长尾动词 / 句式变体 / 上下文指代 / 查询长尾 / 时间长尾 / 该拒的（F–K 桶） | 探针 |
| `round-02.mjs` | 换一批全新说法，验第一轮补丁是否真泛化 | 探针 |
| `round-03.mjs` | 全新语料，另加三类结构性上限（多动作单句 / 同音错字 / 农历节日） | 探针 |
| `round-04.mjs` | 改动之后才第一次写出来的句子，拿干净的泛化数 | 探针 |
| `round-05.mjs` | 多动作单句拆分：该拆的与不该拆的，正反两向 | 探针 |
| `round-06.mjs` | 无分隔连写多动作（「把A删了把B标成高」） | 探针 |
| `round-07.mjs` | 前六轮补齐后的诚实泛化数（L 新说法 / M 会话回指 / N 时间 / O 该保守的） | **硬门** |
| `round-08.mjs` | 泛化主数 P/Q + 已知上限板 R（不计分）+ 该保守的 S（含安全底线） | **硬门** |

## 维护约定

- 加新一轮 = 复制 `round-08.mjs` 改语料与文件头，**先记录首跑成绩、再动手补**
  （补完再写就是对着答案出题）；文件名顺延 `round-09.mjs`，总入口自动收入。
- 新硬门要在总入口的 `GATE` 集合里登记（`scripts/qa-nl-heldout.mjs`）。
- 判分口径不变：认不准一律走澄清，**绝不静默执行**；会直接改文件的动作必须
  `needsConfirm` 或低置信二选一 —— 这一条由硬门轮次的「安全底线」分组守着。
